# 08: `fs`

**What to build:** `require("fs")` — files and directories, so a script can do
the thing scripts most often do without `io`'s handle dance: read and write
whole files, list a directory, glob for a pattern, ask what a path is, create
and remove things, and read metadata.

**Blocked by:** 01 (async-first execution), 04 (module selection).

**Status:** ready-for-agent

Genuinely blocked by 01: every operation here is asynchronous, so there is
nothing to run it under until the async conversion has landed.

- [ ] Read and write whole files as strings, reachable through `require`.
- [ ] List a directory, and glob for a pattern.
- [ ] Ask whether a path exists and whether it is a file or a directory.
- [ ] Create and remove files and directories, including recursively.
- [ ] Read metadata: at least size and modified time.
- [ ] Every failure — missing file, permission denied, not a directory — raises a Lua error a script can `pcall`, carrying enough of the underlying cause to act on.
- [ ] Tests run under the existing temporary-directory helper, which is the prior art for this and needs no changes.
- [ ] Carries the attribution header settled in 05, with its own `Changes from the original:` list.

`glob` is in on the author's call, against the recommendation to drop it. It was
verified as `rust-lang/glob`, MIT OR Apache-2.0, current at 0.3.4 against
Astra's 0.3.3.
